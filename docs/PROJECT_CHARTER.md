# AgentScratch 项目立项记录

> 立项日期：2026-09-03  
> 项目定位：面向初学者的“Agent 界的 Scratch”，用可视化拖拽方式帮助用户理解真实 LLM Agent 的运行原理。

## 一、项目定位

AgentScratch 是一个本地优先的 Agent 教学创作器。用户通过积木式拖拽编排 Agent，观察真实 Transformer 小模型在上下文中进行观察、思考、选择动作、调用工具、接收结果并循环决策的完整过程。

核心目标不是做一个通用 Agent 平台，而是做一个教学产品：

1. 让初学者直观理解 Agent 的核心循环。
2. 使用真实本地 LLM，而不是规则 Mock。
3. 不依赖云端大模型 API。
4. 支持单步执行、慢速播放、事件时间线、失败回放。
5. 可部署到学校机房、培训机构和企业内训场景。

## 二、最终推荐技术方案

### 技术路线

**采用 Python + TypeScript 的 Web-first 架构，不采用 C++/Qt 作为第一阶段主线。**

```text
前端：TypeScript + React + Blockly / React Flow
后端：Python + FastAPI
模型：本地 Qwen 小模型 + llama.cpp / GGUF
核心：Agent DSL + Agent Interpreter + Tool Runtime
交付：课堂服务器优先，后续可选桌面壳
```

### 推荐架构

```text
┌────────────────────────────────────┐
│ Scratch-like Agent Builder          │
│ 积木拖拽 / 连线 / 配置工具           │
└──────────────────┬─────────────────┘
                   ↓
          Mini Agent DSL JSON
                   ↓
        ┌──────────────────┐
        │ Agent Interpreter │
        │ 循环 / 状态 / 事件 │
        └────────┬─────────┘
                 ↓
        ┌──────────────────┐
        │ TinyLLMBrain      │
        │ 本地 Transformer   │
        │ 真实生成 action     │
        └────────┬─────────┘
                 ↓
        ┌──────────────────┐
        │ Action Validator  │
        │ Schema / 白名单    │
        └────────┬─────────┘
                 ↓
        ┌──────────────────┐
        │ Tool Runtime      │
        │ calculator/search/memory
        └────────┬─────────┘
                 ↓
        ┌──────────────────┐
        │ Event Timeline    │
        │ 单步执行 / 回放    │
        └──────────────────┘
```

### 关键设计决策

1. **默认使用真实 LLM Brain**  
   教学主线必须使用真实 Transformer 模型。MockBrain 只作为测试和调试工具，不作为主教学体验。

2. **小模型 + 强输出约束**  
   使用 Qwen 0.5B / 0.6B / 1.7B 级别本地模型，通过 JSON Schema / Grammar 约束输出，但保留模型自主决策能力，不能用规则替代模型选择。

3. **模型学习通用工具调用协议**  
   不把工具名写死在模型里。工具 schema 在运行时注入，让模型基于当前上下文选择工具和参数。

4. **训练方案与产品分离**  
   第一阶段先实现产品闭环和数据采集；模型微调、数据集和评测体系在第二阶段重点展开。

5. **课堂服务器交付优先**  
   学校机房部署一台课堂服务器，学生使用浏览器访问，避免每个学生机器都需要高配置。

## 三、商业模式方向

商业策略为：**公开内容获取影响力，闭源产品面向 B 端交付，服务和课程持续变现。**

### 公开层

- 教学视频
- Agent 原理讲解
- 产品 Demo
- 部分免费课件
- 商务联系方式

### 闭源 / 商业层

- AgentScratch 完整产品
- Agent 解释器
- Tool Runtime
- 官方微调模型
- 课程体系
- 教师后台
- 学生实验记录
- 课堂管理系统
- 私有化部署
- 年度维护和更新

### 商业护城河

项目不依赖“闭源训练方案无法被复现”作为核心壁垒。真正护城河来自：

1. 课程体系
2. 教师服务
3. 学校交付能力
4. 真实课堂反馈数据
5. 官方模型持续优化
6. 评测体系
7. 渠道关系
8. 品牌和认证

## 四、与现有代码的关系

现有两个项目只作为参考，不作为新产品底座：

- `YiNengFactory-main`：参考其事件模型、Trace 概念、工作流执行思想，不直接作为教学产品框架。
- `workflow-console-poc-main`：参考其 ReactFlow 使用方式和运行状态可视化，不继续在其上改造。
- `AgentScratch`：新项目，从零实现面向初学者的交互模型和教学体验。
